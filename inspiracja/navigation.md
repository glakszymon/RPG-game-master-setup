# Navigation & Canvas

[Docs](https://mithos.app/docs/) / Navigation & Canvas

MITHOS uses a free-form canvas. Every tool opens as its own floating window. You can have as many windows open at once as you need, arranged however makes sense for your session.

## Opening Tools

Right-click anywhere on the canvas to open the context menu. Tools are grouped by category:

| Group                | Tools                                                |
| -------------------- | ---------------------------------------------------- |
| **Combat Tools**     | Party Tracker, Combat Tracker                        |
| **NPC Management**   | NPC Generator, NPC Library, Bestiary                 |
| **World & Time**     | Weather Generator, Calendar, Time Tracker            |
| **Tables & Content** | Shop Generator, Library, Roll Tables, Session Viewer |
| **Audio / Visual**   | Map Display, Sound Board                             |

Click any tool name to open it. If it is already open, clicking it again closes it. Open tools show a small filled indicator next to their name.

## Moving & Resizing Windows

- **Move** – drag the title bar to reposition a window anywhere on the canvas.
- **Resize** – hover any edge or corner of a window until the resize cursor appears, then drag. On mobile/touch, long-press an edge to enter resize mode.
- **Minimize** – click the minus (-) button in the title bar to collapse a window to its title bar only. Click it again to restore.
- **Close** – click the close (×) button in the title bar.

## Canvas Navigation

| Action                      | Result            |
| --------------------------- | ----------------- |
| Scroll wheel                | Zoom in / out     |
| Two-finger trackpad gesture | Pan the canvas    |
| Middle mouse button + drag  | Pan the canvas    |
| Alt + drag                  | Pan the canvas    |
| Right-click                 | Open context menu |

## Keyboard Shortcuts

| Shortcut                 | Action                          |
| ------------------------ | ------------------------------- |
| `Ctrl + =` or `Ctrl + +` | Zoom in                         |
| `Ctrl + -`               | Zoom out                        |
| `Ctrl + 0`               | Reset zoom to default           |
| `Ctrl + Alt + T`         | Reroll the tip/headline display |
| `Escape`                 | Close open dialogs              |
| `Enter`                  | Confirm dialogs                 |

## Focus Presets

A **Focus** is a saved snapshot of which windows are open, where they are positioned, and what zoom level the canvas is at. Focuses let you switch instantly between different layouts, for example, one layout for combat and another for roleplay scenes.

### Saving a Focus

1. Arrange your windows and zoom as desired.
2. Right-click the canvas to open the context menu.
3. Click **Save current as focus** at the bottom of the menu.
4. Enter a name and confirm.

### Loading a Focus

Open the context menu and click any named focus in the **Focuses** section. All windows will snap to the saved positions and the canvas will restore the saved zoom.

### Updating a Focus

Click the save icon (floppy disk) next to a focus name in the context menu to overwrite it with the current window layout.

### Deleting a Focus

Click the trash icon next to a focus name in the context menu.

### Last Setup

If you have not saved any named focuses, the context menu shows a **Use last setup** option that restores the most recent auto-saved window arrangement.

## Floating Utilities

Three utilities live in the bottom-left corner of the screen, always on top of the canvas:

- **Recorder** – audio recorder for session notes
- **Sticky Notes** – quick scratch pad
- **Dice Dock** – dice roller

Each can be shown or hidden from [Settings](https://mithos.app/docs/navigation-canvas/settings.md).

## Top-Right Menu

The three-dot (⋯) button in the top-right corner opens the app menu:

- **Campaigns** – switch between or create campaigns
- **Settings** – appearance and utility options
- **Controls** – keyboard shortcut reference
- **Credits** – contributors list
- **Terms of Service**
- **Join Discord** – community link
- **Report a Bug** – email link
- **Close** – exit the application
