# Notes & Session Viewer

[Docs](https://mithos.app/docs/) / Notes & Session Viewer

The Session Viewer is a full rich-text note editor for session notes, lore documents, NPC write-ups, or anything else you want to keep at hand during play. Open it from the right-click context menu under **Tables & Content > Session Viewer**.

## Interface Layout

The Session Viewer has two main areas:

- **File Explorer sidebar** (left) — lists your notes files and folders
- **Editor pane** (right) — the active note

## Creating Notes

Click the **+** (new file) button in the sidebar to create a new note. Give it a name when prompted.

Click the folder icon to create a folder for organising notes.

## Rich Text Editing

The editor supports full rich text formatting via the toolbar at the top of the editor pane:

| Format                 | How to apply               |
| ---------------------- | -------------------------- |
| **Bold**               | Toolbar button or `Ctrl+B` |
| **Italic**             | Toolbar button or `Ctrl+I` |
| **Underline**          | Toolbar button or `Ctrl+U` |
| Headings (H1–H3)       | Toolbar heading selector   |
| Bullet list            | Toolbar list button        |
| Numbered list          | Toolbar list button        |
| Task list (checkboxes) | Toolbar task list button   |
| **Tables**             | Insert via toolbar         |
| Code block             | Toolbar code button        |
| Horizontal rule        | Toolbar divider button     |

The editor also supports pasting Markdown — content pasted from a Markdown source is converted to formatted text automatically.

## File Explorer

The sidebar lists all notes for the active campaign. Click a note to open it. Drag notes between folders to reorganise.

Right-click a note or folder for options: rename, delete, or move.

## OneNote Integration

If you use Microsoft OneNote, you can link MITHOS to your OneNote notebooks:

1. Click the OneNote icon in the Session Viewer toolbar.
2. A device code authentication modal appears. Follow the on-screen instructions to sign in with your Microsoft account.
3. Once linked, your OneNote notebooks and pages appear in the sidebar alongside local notes.

> OneNote integration requires an internet connection and a Microsoft account.

## Auto-save

Notes are saved automatically as you type. There is no manual save button required.
