# Bestiary

[Docs](https://mithos.app/docs/) / Bestiary

The Bestiary is a searchable library of enemies and monsters. Open it from the right-click context menu under **NPC Management > Bestiary**.

## Browsing the Bestiary

Enemies are displayed as cards or rows. Use the **search bar** at the top to filter by name. You can also filter by folder or tags.

## Adding Enemies

Click the **Plus (+)** button to create a new entry. The stats displayed on the enemy card will automatically match the stats you have made visible in the combat tracker.

## Organizing Your Bestiary

Enemies can be organized into custom folders created within the Bestiary. You can group them by encounter, creature type, or any other category that fits your campaign.

- **To create a folder:** Click the **Folder Icon**.
- **To manage your view:** Click a folder name to expand or collapse its contents.

## Tagging and Filtering

You can add tags to enemies for quick filtering. Tags are campaign-specific and can be customized using the color picker or by entering a hex code.

To find specific entries, use the search bar or the filter bar at the top of the screen to sort by your active tags.

## Adding Enemies to Combat

To add an enemy to the combat tracker, you can drag the enemy card directly into the tracker. Alternatively, dragging an enemy card onto the map display tool will automatically add it to the combat tracker as well.

## Enemy Tokens

You can also choose a specific token for each of your enemies. When you bring an enemy into the Map Display Tool, that designated token will be the one shown on the map to represent them.

## Editing & Deleting

Click on an enemy to open its detail view for editing. Use the delete button in the detail view to remove an enemy from the library permanently.

## JSON Import Tool

You can import enemies using a JSON file. The system recognizes entries within any JSON file, allowing you to bring in full libraries of enemies from any game system.

Using the import tool, you can map the data fields from your JSON file to the specific stats you have configured for your current Bestiary. This ensures that imported creatures align perfectly with your existing setup.
